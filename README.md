# Lampa Player для iPhone

Свой плеер для Lampa и торрентов (TorrServer) на iOS. Ядро — mpv/FFmpeg через [MPVKit](https://github.com/mpvkit/MPVKit) (LGPL), поэтому играет MKV, HEVC/AV1, AC3/E-AC3/DTS, ASS/SRT/PGS.

Идея взята у [DDD Player](https://github.com/usmanec/dddplayer) для Android: плейлисты, внешние субтитры, все дорожки и автовыбор языка. 3D здесь нет.

## Как плеер получает видео от Lampa

На iPhone Lampa умеет отдавать видео только «известным» плеерам через их URL-схемы. Этот плеер регистрирует схемы `infuse://` и `senplayer://` и прикидывается ими:

| Что выбрать в Lampa | Что придёт |
|---|---|
| **Infuse** (рекомендуется) | плейлист сезона (до 40 серий), позиция продолжения, имена файлов, внешние субтитры |
| **SenPlayer** | одна ссылка |

Lampa ставит выбранную серию первой и поворачивает список (5, 6, … 10, 1, 2, 3, 4). Плеер возвращает исходный порядок по номерам серий.

**Важно:** настоящие Infuse и SenPlayer на телефоне держать не надо. Если схему зарегистрировали два приложения, iOS сама решает, какое открыть.

Ещё есть своя схема: `lampaplayer://play?url=<encoded>&title=<encoded>&position=<сек>&sub=<encoded>`.

## Настройка Lampa

1. Настройки → Плеер → тип плеера → **Infuse**. Если для торрентов выбор отдельный, там тоже Infuse.
2. Настройки → TorrServer → адрес вашего TorrServer. Телефон должен до него доставать: в домашней сети или по внешнему адресу/VPN. TorrServer на самом iPhone не запускается, ему нужен компьютер, роутер или VPS.
3. При первом заходе на TorrServer в локальной сети iOS спросит доступ к локальной сети, надо разрешить.

## Что умеет MVP

- Плейлист: следующая/предыдущая серия, автопереход, список серий с прогрессом.
- Озвучки и субтитры (встроенные и внешние от Lampa). Выбранная вручную озвучка переносится на следующие серии.
- Автовыбор озвучки и субтитров по языку системы или по языку из настроек. Если озвучка на вашем языке, включаются только форсированные субтитры.
- Позиция просмотра запоминается локально. Lampa не узнаёт прогресс от внешнего плеера на iOS, поэтому и отметки «просмотрено» в Lampa не будет.
- Двойной тап слева/справа перематывает на ±10 с, по центру переключает «вписать/заполнить», щипок тоже. Есть выбор скорости.
- Буферизация показывает процент и скорость, это удобно на торрентах. Если поток оборвался, плеер предлагает «Повторить» с того же места и не засчитывает серию как досмотренную.
- Главный экран: открыть ссылку руками, история.

## Сборка

Нужен macOS с Xcode. На Windows собирать в GitHub Actions:

1. Залить папку в репозиторий GitHub. Для публичного репо минуты macOS бесплатные, у приватного они списываются в 10 раз быстрее.
2. Workflow `.github/workflows/build.yml` запускается на push в `main` или вручную (Actions → Build IPA → Run workflow).
3. Скачать артефакт `LampaPlayer-unsigned-ipa`, внутри неподписанный `LampaPlayer-unsigned.ipa`.

Локально на Mac:

```bash
brew install xcodegen
xcodegen generate
open LampaPlayer.xcodeproj
```

## Установка на iPhone

IPA собирается без подписи. Подписать его можно своим сертификатом (p12 + mobileprovision) через Esign / Feather / KSign / Scarlet на телефоне или через `zsign` на компьютере. Bundle ID — `com.lampaplayer.app`, подписчик может заменить его на свой.

Особых entitlements нет: URL-схемы, HTTP без TLS и доступ к локальной сети работают с любым сертификатом.

## Устройство

- `LaunchParser.swift` — разбор `infuse://` / `senplayer://` / `lampaplayer://`, возврат порядка серий.
- `PlayerModel.swift` — libmpv (vo=gpu-next через MoltenVK, hwdec=videotoolbox), события, дорожки, позиции.
- `PlayerView.swift` — экран плеера на SwiftUI.
- `HomeView.swift`, `Storage.swift` — главный экран, история, позиции.
- `LampaPlayer/Fonts/Roboto-Regular.ttf` — шрифт с кириллицей для субтитров (`sub-fonts-dir`).
