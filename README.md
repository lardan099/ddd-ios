# Lampa Player для iPhone

Свой плеер для Lampa и торрентов на iOS. Ядро — mpv/FFmpeg ([форк MPVKit от Streamyfin](https://github.com/streamyfin/MPVKit) с выводом `vo=avfoundation`), поэтому играет MKV, HEVC/AV1, AC3/E-AC3/DTS/TrueHD, ASS/SRT/PGS. Внутри есть встроенный TorrServer, так что торренты смотрятся без компьютера и VPS.

Идея взята у [DDD Player](https://github.com/usmanec/dddplayer) для Android: плейлисты, внешние субтитры, все дорожки и автовыбор языка. 3D здесь нет.

## Возможности

**Воспроизведение**
- 4K: HEVC и H.264 декодируются аппаратно (VideoToolbox). AV1 аппаратно декодируется только на iPhone 15 Pro и новее, на остальных программно.
- HDR10/HLG выводятся как настоящий HDR (EDR) на iOS 17+. Dolby Vision profile 7/8 играет как HDR10.
- Картинка в картинке: кнопка в плеере и автоматически, когда смахиваешь приложение на домашний экран. Субтитры видны и в PiP.
- Озвучки и субтитры: встроенные и внешние от Lampa. Автовыбор по языку системы или языку из настроек. Выбранная вручную озвучка переносится на следующие серии.
- Задержка звука и субтитров (шаг 0,1 с), размер субтитров (запоминается).
- Позиция просмотра запоминается для каждой серии. Если поток оборвался, плеер предлагает «Повторить» и не считает серию досмотренной.

**Управление**
- Двойной тап слева/справа: −10 / +10 с.
- Свайп вверх-вниз: слева яркость, справа громкость.
- Свайп влево-вправо: перемотка с превью времени.
- Щипок: вписать или заполнить экран.
- Блокировка экрана от случайных касаний.
- Работает вертикально и горизонтально. Кнопка «повернуть» срабатывает и при включённой блокировке поворота.
- Наушники, экран блокировки, Пункт управления: плей/пауза, двойное нажатие — следующая серия, тройное — предыдущая (у одиночного видео это ±30 с), перемотка и ползунок. Пока плеер открыт, «плей» управляет им, а не Музыкой.
- Если вынуть наушники, плеер встаёт на паузу. При звонке тоже пауза, после звонка воспроизведение продолжается.

**Диагностика**
- В плеере ⋯ → «Тех. данные и лог»: источник, сеть и кэш, видео (кодек, разрешение, декодер, HDR-параметры, пропущенные кадры), аудио, субтитры, лог mpv и TorrServer. Есть кнопка «Скопировать».
- На главном экране TorrServer → «Журнал запросов Lampa»: каждый запрос Lampa и ответ сервера.

## Как плеер получает видео от Lampa

На iPhone Lampa умеет отдавать видео только «известным» плеерам через их URL-схемы. Этот плеер регистрирует схемы `infuse://` и `senplayer://` и прикидывается ими:

| Что выбрать в Lampa | Что придёт |
|---|---|
| **Infuse** (рекомендуется) | плейлист сезона (до 40 серий), позиция продолжения, имена файлов, внешние субтитры |
| **SenPlayer** | одна ссылка |

Lampa ставит выбранную серию первой и поворачивает список (5, 6, … 10, 1, 2, 3, 4). Плеер возвращает исходный порядок по номерам серий.

**Важно:** настоящие Infuse и SenPlayer на телефоне держать не надо. Если схему зарегистрировали два приложения, iOS сама решает, какое открыть.

Ещё есть своя схема: `lampaplayer://play?url=<encoded>&title=<encoded>&position=<сек>&sub=<encoded>`.

## Встроенный TorrServer

[TorrServer](https://github.com/YouROK/TorrServer) (библиотека TorrServerKit из его релизов) работает прямо в приложении.

1. Главный экран → TorrServer → включить «Встроенный TorrServer».
2. «Проверить» должно показать «Отвечает, версия MatriX…».
3. В Lampa: Настройки → TorrServer → адрес `http://127.0.0.1:8090`.

Как это устроено:
- Сам TorrServer слушает `127.0.0.1:8095`. На `8090` стоит маленький прокси приложения. В TorrServer зашит бан запросов с Referer/Origin популярных зеркал Lampa (`bylampa.online`, `lampa.land` и др.), выключить его нельзя. Прокси убирает эти заголовки, а CORS продолжает работать. Плеер ходит на `8095` напрямую, мимо прокси.
- Пока Lampa открыта в Safari, приложение в фоне. Чтобы iOS его не заморозила, включён режим «Работать в фоне»: приложение проигрывает тишину и не глушит другую музыку. Это тратит немного батареи, режим можно выключить.
- Если Lampa открыта по `https`, Safari может блокировать запросы к `http://127.0.0.1`. Тогда откройте Lampa по `http` или как веб-приложение с домашнего экрана.
- Когда приложение долго в фоне без режима «Работать в фоне», iOS его замораживает, и Lampa снова пишет «не удалось подключиться». Достаточно открыть плеер и вернуться в Lampa.

Можно и без встроенного: укажите в Lampa адрес своего TorrServer на компьютере, роутере или VPS. Телефон должен до него доставать.

## Настройки (главный экран)

- **Видеовывод.** AVFoundation (по умолчанию) — это PiP и HDR. libplacebo — без PiP, но точнее цвета Dolby Vision profile 5 (часто в WEB-DL). Если видео фиолетово-зелёное, переключитесь на libplacebo.
- **HDR**, **картинка в картинке при сворачивании**, **аппаратное декодирование**: выключите последнее, если на каком-то видео артефакты.
- **Язык озвучки и субтитров**: как в системе, русский, украинский или английский.

## Сборка

Нужен macOS с Xcode. На Windows собирать в GitHub Actions:

1. Push в `main` или вручную: Actions → Build IPA → Run workflow.
2. Скачать артефакт `LampaPlayer-unsigned-ipa`, внутри `LampaPlayer-<версия>-<сборка>-unsigned.ipa`.

Номер сборки равен номеру прогона CI и растёт сам. Версию видно внизу главного экрана, по ней можно убедиться, что встала новая сборка.

Локально на Mac:

```bash
bash tools/fetch-vendor.sh
```

```bash
brew install xcodegen
```

```bash
xcodegen generate && open LampaPlayer.xcodeproj
```

`tools/fetch-vendor.sh` кладёт TorrServerKit в `Vendor/`. libmpv подтягивается Swift-пакетом `Packages/MPVKitAV`.

## Установка на iPhone

IPA собирается без подписи. Подписать его можно своим сертификатом (p12 + mobileprovision) через Esign / Feather / KSign / Scarlet на телефоне или через `zsign` на компьютере. Bundle ID — `com.lampaplayer.app`.

Нужен только фоновый режим `audio`, он уже прописан в Info.plist. Особых entitlements нет.

Если после обновления на телефоне осталась старая иконка или поведение, проверьте версию внизу главного экрана.

## Устройство

| Файл | Что внутри |
|---|---|
| `LaunchParser.swift` | разбор `infuse://` / `senplayer://` / `lampaplayer://`, возврат порядка серий |
| `PlayerModel.swift` | libmpv: все вызовы только на очереди mpv (avfoundation-вывод синхронно ходит в главный поток), дорожки, позиции, тех. данные |
| `PlayerView.swift`, `PlayerSheets.swift` | экран плеера, жесты, шторки дорожек, задержек и тех. данных |
| `PiPController.swift` | картинка в картинке поверх `AVSampleBufferDisplayLayer` |
| `RemoteControls.swift` | наушники, экран блокировки, «Сейчас играет», пауза при отключении наушников и звонке |
| `TorrServerManager.swift`, `LocalProxy.swift` | встроенный TorrServer, прокси на :8090, работа в фоне |
| `HomeView.swift`, `Storage.swift` | главный экран, настройки, история, позиции |
| `Packages/MPVKitAV` | Swift-пакет с libmpv (форк MPVKit 0.41.0-av5) |
| `tools/make_icon.py` | генерация иконки |
