# Lampa Player для iPhone

Lampa и свой плеер в одном приложении для iOS. Lampa открывается прямо внутри, видео идёт сразу в нативный плеер, отметки просмотра возвращаются в Lampa. Встроенный TorrServer позволяет смотреть торренты без компьютера и VPS.

Ядро плеера — mpv/FFmpeg ([форк MPVKit от Streamyfin](https://github.com/streamyfin/MPVKit) с выводом `vo=avfoundation`), поэтому играет MKV, HEVC/AV1, AC3/E-AC3/DTS/TrueHD, ASS/SRT/PGS.

Идея взята у [DDD Player](https://github.com/usmanec/dddplayer) для Android: плейлисты, внешние субтитры, все дорожки и автовыбор языка. 3D здесь нет.

## Lampa внутри приложения

При запуске открывается ваша Lampa (адрес задаётся в настройках, по умолчанию `http://lampa.byskaz.ru`).

- Плагин плеера встраивается сам, добавлять его в Lampa не нужно.
- Видео из Lampa (онлайн и торренты) открывается сразу в плеере, без переключения приложений. Закрыли плеер — вернулись в Lampa на то же место.
- Отметки просмотра ставятся в Lampa сразу после закрытия плеера, с синхронизацией в аккаунт.
- Картинка в картинке поверх Lampa: включили PiP — плеер сворачивается, Lampa можно листать, серия идёт в окошке. «Развернуть» в окне PiP возвращает плеер с того же места, крестик заканчивает просмотр (и ставит отметку). Открыли из Lampa другое видео — старое закрывается.
- TorrServer работает в том же приложении, поэтому ни Safari, ни работа в фоне не нужны.
- mpv ходит с тем же User-Agent, что и встроенная Lampa: часть CDN привязывает подпись ссылки к браузеру.
- Настройки плеера — пункт «Lampa Player» в меню Lampa (пока он не появился, в углу есть кнопка-шестерёнка).

В Lampa тип плеера должен быть **Infuse** (и для торрентов тоже). Встроенный режим выключается в настройках: «Экран плеера вместо Lampa» или переключатель «Открывать Lampa при запуске».

## Возможности плеера

**Воспроизведение**
- 4K: HEVC и H.264 декодируются аппаратно (VideoToolbox). AV1 аппаратно декодируется только на iPhone 15 Pro и новее, на остальных программно.
- HDR10/HLG выводятся как настоящий HDR (EDR) на iOS 17+. Dolby Vision profile 7/8 играет как HDR10.
- Картинка в картинке: кнопка в плеере и автоматически, когда смахиваешь приложение на домашний экран. Субтитры видны и в PiP.
- Озвучки и субтитры: встроенные и внешние. Автовыбор по языку системы или языку из настроек: озвучка на вашем языке — только форсированные субтитры, иначе полные. Выбранная вручную озвучка переносится на следующие серии.
- Пропуск заставок, титров и рекламы по меткам балансера (например, MODS's): кнопка «Пропустить», автопропуск или выключено. Метки видны на полосе перемотки: жёлтые — заставки и титры, красные — реклама.
- Отсчёт «Следующая серия через N» на титрах (по метке, без меток — за 20 с до конца) с кнопками «Смотреть» и «Отмена». На паузе отсчёт замирает.
- Превью кадров при перемотке, если балансер их даёт.
- Задержка звука и субтитров (шаг 0,1 с), размер субтитров. Размер и скорость воспроизведения запоминаются.
- Позиция просмотра запоминается для каждой серии. Если поток оборвался, плеер предлагает «Повторить» и не считает серию досмотренной.

**Управление**
- Двойной тап слева/справа: −10 / +10 с.
- Свайп вверх-вниз: слева яркость, справа громкость. Свайпы от верхнего и нижнего края (шторка, Пункт управления, «домой») не трогают яркость и громкость.
- Свайп влево-вправо: перемотка с превью времени и кадра.
- Щипок: вписать или заполнить экран.
- Блокировка экрана от случайных касаний.
- Работает вертикально и горизонтально. Кнопка «повернуть» срабатывает и при включённой блокировке поворота.
- Наушники, экран блокировки, Пункт управления: плей/пауза, двойное нажатие — следующая серия, тройное — предыдущая (у одиночного видео это ±30 с), перемотка и ползунок. Пока плеер открыт, «плей» управляет им, а не Музыкой.
- Если вынуть наушники, плеер встаёт на паузу. При звонке тоже пауза, после звонка воспроизведение продолжается.

**Диагностика**
- В плеере ⋯ → «Тех. данные и лог»: источник, сеть и кэш, видео (кодек, разрешение, декодер, HDR-параметры, пропущенные кадры), аудио, субтитры, лог mpv и TorrServer. Есть кнопка «Скопировать».
- Настройки → TorrServer → «Журнал запросов Lampa»: каждый запрос Lampa и ответ сервера.

## Плагин для Lampa

Во встроенной Lampa плагин подключён сам. Для Lampa в Safari или на другом iPhone его можно добавить вручную:

1. Lampa → Настройки → Расширения → Добавить плагин: `https://lardan099.github.io/lampa-player-plugin/lampa-player.js`.
2. Тип плеера оставить **Infuse**.

Плагин перехватывает в Lampa открытие «внешнего плеера Infuse» и передаёт плееру всё: серии, все субтитры, метки пропуска, превью кадров, позицию и ключ отметки просмотра. Без плагина Lampa отдаёт Infuse урезанные данные: один файл субтитров, без меток и без отметок.

Отметки просмотра плагин ставит через `Lampa.Timeline`. Во встроенной Lampa — сразу после закрытия плеера. В Safari — при возврате в Lampa, забирая позиции с `http://127.0.0.1:8090/lampaplayer/progress`.

Исходник — `plugin/lampa-player.js`, тест на моке Lampa — `node plugin/test-plugin.js`. Тот же файл кладётся в приложение и публикуется в репозитории [lampa-player-plugin](https://github.com/lardan099/lampa-player-plugin) (GitHub Pages). При правке плагина надо обновить и опубликованную копию.

Ссылка `lampaplayer://lampa?d=<base64url(JSON)>`: `{ v, i, c: {title, original, poster}, items: [{ u, t, s: [{u, l}], g: {a, s, d}, v, h, p }] }`.

## Без плагина: схемы Infuse и SenPlayer

Плеер регистрирует схемы `infuse://` и `senplayer://` и прикидывается этими плеерами:

| Что выбрать в Lampa | Что придёт |
|---|---|
| **Infuse** (рекомендуется) | плейлист сезона (до 40 серий), позиция продолжения, имена файлов, одни внешние субтитры |
| **SenPlayer** | одна ссылка |

Lampa ставит выбранную серию первой и поворачивает список (5, 6, … 10, 1, 2, 3, 4). Плеер возвращает исходный порядок по номерам серий.

**Важно:** настоящие Infuse и SenPlayer на телефоне держать не надо. Если схему зарегистрировали два приложения, iOS сама решает, какое открыть.

Своя схема для ручного запуска: `lampaplayer://play?url=<encoded>&title=<encoded>&position=<сек>&sub=<encoded>`.

## Встроенный TorrServer

[TorrServer](https://github.com/YouROK/TorrServer) (библиотека TorrServerKit из его релизов) работает прямо в приложении.

1. Настройки → TorrServer → включить «Встроенный TorrServer».
2. «Проверить» должно показать «Отвечает, версия MatriX…».
3. В Lampa: Настройки → TorrServer → адрес `http://127.0.0.1:8090` (слэш на конце не мешает).

Как это устроено:
- Сам TorrServer слушает `127.0.0.1:8095`. На `8090` стоит маленький прокси приложения. В TorrServer зашит бан запросов с Referer/Origin популярных зеркал Lampa (`bylampa.online`, `lampa.land` и др.), выключить его нельзя. Прокси убирает эти заголовки (CORS продолжает работать) и схлопывает лишние слэши в путях. Плеер ходит на `8095` напрямую.
- На том же `8090` живёт API плеера для плагина: `/lampaplayer/ping`, `/progress`, `/ack`. Он работает всегда, даже если TorrServer выключен.
- Для Lampa в Safari: пока она открыта, приложение в фоне, и iOS может его заморозить. Режим «Работать в фоне» держит приложение живым тихим звуком (другую музыку не глушит, немного тратит батарею). Во встроенной Lampa это не нужно.

Можно и без встроенного: укажите в Lampa адрес своего TorrServer на компьютере, роутере или VPS.

## Настройки

- **Lampa:** адрес, «Открывать Lampa при запуске», переход между Lampa и экраном плеера.
- **Плагин для Lampa:** адрес плагина, режим пропуска заставок и рекламы, сколько отметок ждут отправки.
- **TorrServer:** включение, проверка, журнал запросов, работа в фоне, веб-интерфейс.
- **Видео:** видеовывод (AVFoundation — PiP и HDR; libplacebo — без PiP, но точнее цвета Dolby Vision profile 5: если видео фиолетово-зелёное, переключитесь на него), HDR, картинка в картинке при сворачивании.
- **Общие:** язык озвучки и субтитров, аппаратное декодирование, отсчёт до следующей серии, очистка истории.

## Сборка

Нужен macOS с Xcode. На Windows собирать в GitHub Actions:

1. Push в `main` или вручную: Actions → Build IPA → Run workflow. Коммиты с `[skip ci]` в сообщении сборку не запускают — так экономятся минуты Actions.
2. Скачать артефакт `LampaPlayer-unsigned-ipa`, внутри `LampaPlayer-<версия>-<сборка>-unsigned.ipa`.

Номер сборки равен номеру прогона CI и растёт сам. Версию видно внизу экрана настроек.

Локально на Mac:

```bash
bash tools/fetch-vendor.sh
```

```bash
brew install xcodegen
```

```bash
xcodegen generate && open LampaPlayer.xcodeproj
```

`tools/fetch-vendor.sh` кладёт TorrServerKit в `Vendor/`. libmpv подтягивается Swift-пакетом `Packages/MPVKitAV`.

## Установка на iPhone

IPA собирается без подписи. Подписать его можно своим сертификатом (p12 + mobileprovision) через Esign / Feather / KSign / Scarlet на телефоне или через `zsign` на компьютере. Bundle ID — `com.lampaplayer.app`.

Нужен только фоновый режим `audio`, он уже прописан в Info.plist. Особых entitlements нет.

Если после обновления на телефоне осталась старая иконка или поведение, проверьте версию внизу экрана настроек.

## Устройство

| Файл | Что внутри |
|---|---|
| `LampaWebView.swift` | встроенная Lampa: WKWebView, внедрение плагина, перехват ссылок плеера, отметки просмотра через JS |
| `LaunchParser.swift` | разбор `lampaplayer://lampa` (плагин), `infuse://`, `senplayer://`, возврат порядка серий |
| `PlayerModel.swift` | libmpv: все вызовы только на очереди mpv (avfoundation-вывод синхронно ходит в главный поток), дорожки, сегменты, отсчёт следующей серии, позиции, тех. данные |
| `PlayerView.swift`, `PlayerSheets.swift` | экран плеера, жесты, шторки дорожек, задержек и тех. данных |
| `Thumbnails.swift` | превью кадров из WebVTT-спрайтов |
| `PiPController.swift` | картинка в картинке поверх `AVSampleBufferDisplayLayer` |
| `RemoteControls.swift` | наушники, экран блокировки, «Сейчас играет», пауза при отключении наушников и звонке |
| `TorrServerManager.swift`, `LocalProxy.swift`, `LocalAPI.swift` | встроенный TorrServer, прокси на :8090, API плеера для плагина, работа в фоне |
| `HomeView.swift`, `Storage.swift` | настройки, история, позиции, очередь отметок для Lampa |
| `plugin/lampa-player.js` | плагин Lampa (встраивается в приложение и публикуется на GitHub Pages) |
| `Packages/MPVKitAV` | Swift-пакет с libmpv (форк MPVKit 0.41.0-av5) |
| `tools/make_icon.py` | генерация иконки |
